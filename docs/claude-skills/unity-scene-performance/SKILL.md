# Unity Scene Performance

Optimize scenes according to measured bottlenecks and target hardware.

## Check
- object count;
- renderer count;
- material count;
- shadow cost;
- texture memory;
- LOD usage;
- culling;
- occlusion;
- physics colliders;
- static/dynamic classification;
- scene loading/streaming.

## Rules
Do not apply every optimization technique automatically. Choose the smallest set justified by the scene and target platform.
