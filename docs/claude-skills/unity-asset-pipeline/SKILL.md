# Unity Asset Pipeline

Treat asset imports and references as part of the project's build pipeline.

## Rules
- Reuse existing assets before adding duplicates.
- Preserve naming and folder conventions.
- Do not casually change import settings project-wide.
- Consider texture compression, mesh settings, material compatibility, and animation import settings.
- Keep source assets distinct from generated/runtime assets.

## Quality
Prefer consistent asset standards over ad-hoc per-asset settings.
